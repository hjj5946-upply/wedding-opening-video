# 프로젝트 지침 (최신본)

> 2026-11-02 기준. 예식장 최종 안내 메일을 반영해 이전 지침을 수정했습니다. (변경점은 `03_DECISIONS.md`)

## 1. 목적
- 개식 직후, 하객의 시선을 한 번에 모으는 **오프닝 영상** 제작 (사회자 "예식을 시작하겠습니다" 직후 재생)
- 식전 대기실용 영상이 아님 / 예식장 기준 "식중 영상" 중 오프닝에 해당 (식중 영상은 **1개만** 가능)

## 2. 예식장 규격 (필수)
- 해상도 1920×1080 / **프레임레이트 60** / MP4(H.264 + AAC) / 재생: 팟플레이어
- 길이 2분 이내 (목표 1분 40초~1분 50초) / 용량은 가급적 작게
- 규격을 어기면 재생 시 깨질 수 있음 → 제출 전 팟플레이어에서 직접 재생 확인
- 자세한 내용과 일정: `01_VENUE_SPEC.md`

## 3. 제작 방식
- Claude Code로 Vite + React + GSAP 웹페이지(= 영상) 제작, 1920×1080 고정 캔버스
- 스페이스바로 시작 / 마지막 화면 고정 / 커서 숨김 / 첫 1초 검은 화면
- 문구·타이밍·색은 `src/config.js` 한 곳에서 수정
- 웹은 화면만 담당(말소리 효과음 제외), 음악은 편집 단계에서 입힘
- 무거운 효과 지양, 끊김 최소화

## 4. 녹화 및 마무리
- Windows PC + OBS Studio, 1920×1080, **60fps**, 디스플레이 배율 100%, 브라우저 F11
- 편집 툴(클립챔프/캡컷)에서 앞뒤 자르기 + BGM 3구간 입히기 + **1080p / 60fps / MP4** 내보내기
- 캡컷은 엔딩 로고/워터마크 자동 추가 여부 확인
- 자세한 순서: `04_RECORDING_GUIDE.md`

## 5. 컨셉 (확정)
- 도트 게임풍. STAGE 1(신랑 인사 + 피아노 학원 연애 스토리, 유머) → STAGE 2(달려가며 점프, 신부 만남) → 마지막 카드
- 상세: `02_SCENARIO.md`

## 6. 대화/협업 원칙
- 한국어, 쉽고 상세하게. 영상 제작 용어는 풀어서 설명 (사용자는 영상 편집 경험 없음)
- 사용자가 잘하는 영역(웹/코드)에서 해결하는 방향 우선
- 큰 방향은 먼저 제안하고 세부는 단계별로 확정
- 역할: 깜자(총괄/테스트/결정) · 채팅 Claude(기획/문서/프롬프트) · Claude Code(구현)

## 7. 미확정 사항
- [ ] 페이커 롤드컵 곡명 + 하이라이트 시작 지점(분:초)
- [ ] 슈퍼마리오풍 BGM 정확한 곡 (또는 8비트 대체 음원)
- [ ] 신랑/신부 이름, 예식 날짜 (config.couple)
- [ ] 오프닝 영상 재생 중 예식장 조명 사용 가능 여부 (예식장 문의)
- [ ] 최종확인서(엑셀) 작성 내용 중 영상/BGM 관련 항목
- [ ] 도트 캐릭터 정식 버전 (현재는 임시 코드 도트)
