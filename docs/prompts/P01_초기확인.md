# P01 — 초기 프로젝트 확인 (코드 변경 없음)

아래 전체를 Claude Code에 붙여 넣으세요.

```
먼저 CLAUDE.md 와 README.md, docs/ 폴더의 문서를 읽어 줘.
이 프로젝트는 "웹페이지 자체가 영상"인 결혼식 오프닝 영상이고, 이번 작업은 점검만 하는 거야. 코드는 수정하지 마.

1. 설치와 실행
   - npm install 을 실행하고 에러가 없는지 확인
   - npm run check 결과를 보여줘 (오류 0개여야 함)
   - npm run build 가 성공하는지 확인
   - npm run dev 로 띄운 뒤 브라우저 콘솔에 에러/경고가 없는지 확인

2. 화면 확인 (스크린샷 가능하면 찍어서 보여줘)
   - ?t=4, ?t=41, ?t=56.5, ?t=71, ?t=96, ?t=106 주소로 각각 열어서 장면이 정상인지 확인
   - 1920×1080 화면에서 글자나 말풍선이 잘리거나 겹치는 곳이 있는지 확인

3. 끊김 위험 점검 (60fps 녹화가 목표)
   - STAGE 2 구간(62~92초)에서 transform/레이어 때문에 성능 문제가 생길 만한 부분이 있는지 코드 기준으로 점검
   - 1920×1080, 60fps에서 위험해 보이는 요소가 있으면 목록으로만 알려줘 (수정은 하지 마)

4. 보고 형식 (한국어, 쉽게)
   - 통과한 것 / 문제 있는 것 / 개선 제안 3가지 이내
   - 내가 직접 해봐야 할 확인 사항 (F11 전체화면 → 스페이스바 재생 시 볼 것)
```

## 이 작업이 끝난 뒤 (깜자가 직접 확인)
1. `npm run dev` → 브라우저 F11 → 스페이스바로 처음부터 끝까지 한 번 재생
2. 어색한 부분(타이밍, 글자 크기, 도트 모양 등)을 메모해서 채팅 Claude에게 전달 → 다음 프롬프트(P02)를 작성합니다.
