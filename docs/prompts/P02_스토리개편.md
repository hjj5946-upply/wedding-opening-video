이번 작업은 영상 흐름과 도트 캐릭터를 크게 개편하는 거야. 아래 요구사항 전체를 단계(A~E)로 나눠서 진행하고, 각 단계가 끝날 때마다 ?t=초 주소로 화면을 캡처해서 보여준 뒤 내 확인을 받고 다음 단계로 넘어가 줘.

## 새 영상 흐름 (초 단위는 초안. 멘트 길이에 맞춰 네가 계산해서 조정하되 전체 108초 안팎)
| 시간 | 장면 |
|---|---|
| 0~1 | 완전한 검은 화면 |
| 1~5.5 | 배경 없는 순수 검정 위에서, 신랑이 옆모습으로 화면 오른쪽에서 왼쪽으로 걸어 들어옴 |
| 5.5~23 | 신랑이 화면 왼쪽에 멈춰 앞모습으로 전환, 첫 문장에서 손 흔들며 감사 인사 (큰 말풍선은 오른쪽) |
| 23~26 | 맵이 나타나고 신랑이 위에서 맵으로 떨어져 착지. HUD 등장 |
| 26~38 | 맵 위 피아노 앞에서 짧은 멘트 (피아노는 2D 장애물처럼 서 있음) |
| 38 | GAME START. 맵이 스크롤되며 달리기 시작 (BGM 전환 지점) |
| 38~80 | 달리기. 피아노를 점프로 넘고, 글자 장애물 4개 중 2개는 부딪혀 하트가 깎임. TIME 1 YEAR → 8 YEAR |
| 80~90 | 문장 말풍선 → 신부 등장 → 만남 → 하트 → 둘이 인사 → "STAGE 1 CLEAR!" |
| 90~96 | 화면이 검은색으로 페이드 |
| 96~108 | 검은 화면에 진중한 감사 인사(흰 글씨)가 한 줄씩 나타나고, 마지막까지 고정 |

## 요구사항

### 1. 도트 캐릭터 개편 (임시 도트, 코드로 정의. 나중에 PNG 교체 가능한 구조 유지)
- 도트 격자를 16x24에서 **24x32**로 키워. 렌더 배율은 config에서 조절 가능하게.
- 신랑(검정 정장, 보타이, 가르마 머리) 포즈:
  - 옆모습(오른쪽을 보는 방향으로만 그림): 서기, 걷기 4프레임, 달리기 4프레임, 점프, 피격(맞았을 때)
  - 앞모습: 서기, 손 흔들기 2프레임, 낙하(팔 벌린 포즈)
- 신부(베일 드레스, 갈색 묶은머리, 부케) 포즈: 앞모습 서기, 손 흔들기 2프레임, 옆모습 서기 1프레임(신랑 쪽을 바라봄)
- 왼쪽을 보는 모습은 좌우 반전으로 처리해. **반전은 말풍선까지 뒤집히지 않게** 캐릭터 안의 스프라이트 요소에만 적용해.
- 포즈 트랙(engine/poses.js)은 "구간 + 포즈 + 방향(facing)"을 받아 현재 시각으로 프레임을 결정하게 확장해. 기존처럼 시간으로만 결정돼야 해(?t= 이동과 되감기에서도 정확해야 함).
- 걸음 효과음은 지금 넣지 않고 **훅만 준비**해 줘. 걷기/달리기 프레임이 바뀔 때 발생하는 "발걸음 이벤트"와 config의 sfx.step: { enabled: false, ... } 자리만 만들고, 시간 이동 중에는 소리가 나지 않게 해 줘. 나중에 내가 음원이나 합성음을 연결할 거야.
- PNG 교체 준비: 프레임 이름과 이미지 파일 경로를 연결하는 구조(public/assets/sprites/<캐릭터>/<포즈>_<번호>.png)를 만들고, PNG가 없으면 코드 도트를 쓰게 해. 이번 작업에서는 PNG를 만들 필요 없음.

### 2. 오프닝 변경
- 처음 검은 화면의 **파란 스포트라이트/빛 효과를 완전히 삭제**해. (.spot 및 관련 코드 정리)
- 이 구간에는 배경도 바닥도 없이 순수 검정이야. 신랑은 오른쪽에서 왼쪽으로 옆모습(왼쪽 방향)으로 걸어 들어와.
- 검정 정장이 검정 배경에서 안 보이지 않게 정장 색의 밝기와 하이라이트를 조절해 줘. 가르마 머리 선과 보타이가 또렷해야 해.
- 왼쪽 목표 위치에 멈추면 앞모습으로 바뀌고, 첫 문장("안녕하세요...")이 나오는 동안 손을 흔들어. 이후에는 앞모습 서기이고, 말할 때 살짝 통통 튀는 기존 동작은 유지.

### 3. 말풍선 레이아웃
- 인사 구간: 신랑은 화면 왼쪽(x≈360 부근), 말풍선은 **오른쪽에 크게**, 꼬리는 왼쪽(신랑 방향)을 가리키게.
- 글자는 지금(52px)보다 크게 키워서 64px 안팎으로 시작하고, 3줄까지 화면 안에 깔끔히 들어오는지 캡처로 확인해 크기를 최종 조정해. 뒷자리 하객이 읽을 수 있어야 해.
- 맵 위 구간은 머리 위 말풍선을 써도 되는데, 마찬가지로 크게. 멘트 줄마다 layout: 'side' | 'above' 로 선택할 수 있게 config에 넣어 줘.

### 4. 인사 멘트 (config.dialogue에 반영, config.couple.groom = '홍정준')
1. 안녕하세요. 신랑 {groom}입니다.
2. 날씨도 춥고, 다들 바쁘신 와중에도 저희를 위해 소중한 시간을 내주셔서 감사합니다.
3. 예식 시작 전 간략하게 저희가 어떻게 오늘 이 자리까지 오게 되었는지 말씀 드리겠습니다.
(문장이 길어서 글자 속도는 일단 기본값으로 두고, 읽기 불편하면 보고해 줘.)

### 5. 맵 낙하와 HUD
- 인사가 끝나면 배경이 슈퍼마리오 스타일의 일반적인 플랫포머 맵으로 바뀌고, 신랑이 화면 위에서 낙하해 땅에 착지해(작은 바운스).
- 맵은 하늘, 구름, 언덕, 덤불, 벽돌/물음표 블록 장식, 초록 파이프 정도의 **일반적인 플랫포머 요소**로 그려. 닌텐도의 실제 캐릭터/스프라이트를 그대로 베끼지는 마(모양만 비슷한 오리지널 도트).
- HUD (착지와 함께 등장해서 신부를 만날 때까지 유지)
  - 좌측 상단: 하트 3개 (라이프)
  - 우측 상단: "TIME" 라벨과 "1 YEAR" ~ "8 YEAR". 달리기 진행도(맵 스크롤 거리)에 비례해 1년씩 올라감. config.hud.time = { from: 1, to: 8, unit: 'YEAR' }
  - 영문 HUD용 레트로 폰트로 @fontsource/press-start-2p (OFL) 를 추가해도 좋아. 한글은 기존 Galmuri 유지. 폰트 파일은 번들에 포함돼서 오프라인에서도 보여야 해.
  - HUD 위치/크기는 config에서 조절 가능하게.

### 6. 피아노 → 게임 시작 → 글자 장애물 → 신부
- 착지 후 신랑은 피아노 바로 옆에 서 있어. 피아노는 **옆에서 본 2D 오브젝트**로, 마리오의 파이프처럼 땅에 서 있게 그려 줘.
- 맵 위 멘트(초안, 짧게. 문구는 내가 나중에 config에서 수정할 거야):
  1. 첫 직장에 취직하고, 퇴근 후 취미로 피아노 학원을 다녔는데요.
  2. 거기서 아주 아름다운 선생님을 만났습니다.
  3. 저는 피아노에만 집중하려 했지만... 선생님께 작업만 쳤습니다.
- 그 다음 "GAME START" (제안: "STAGE 1" 배너를 함께 띄워도 좋음)과 함께 신랑이 오른쪽을 보고 달리기 시작. 맵이 스크롤되고 첫 장애물인 피아노를 점프로 넘어.
- 이어서 **글자가 적힌 장애물 4개**가 순서대로 나와: "수많은" / "우여곡절" / "많은" / "일들이". 글자는 장애물 위나 안에 크고 선명하게. 각 장애물에 hit: true|false 를 줘서 **2개는 부딪히고(hit: true) 2개는 점프로 넘어**. 기본값은 "우여곡절", "일들이" 가 hit.
- 부딪히는 연출: 피격 포즈 + 살짝 뒤로 밀렸다 복귀 + 깜빡임 + HUD 하트 하나가 터지듯 사라짐. 하트는 3 → 2 → 1. 절대 0이 되면 안 돼(check 스크립트가 검사하게).
- 부딪히는 시각은 맵 속도와 장애물 위치로 계산해(점프 장애물의 apexAt 방식처럼 config에서 시각 지정 → 위치 자동 계산). 계산 함수는 engine/timing.js 에 두고 check에서도 쓰게.
- 4개 장애물을 지난 뒤 말풍선: "있었지만 8년 6개월을 만났고, 오늘 지금 이 자리, 드디어 STAGE 2탄으로 향해 가려 합니다!"
- 그 순간 맵이 멈추고 신부가 등장. 신랑이 걸어가 만나고(서로 마주 보는 옆모습) 하트가 나오고, 둘 다 앞모습으로 바뀌어 손 흔들며 인사. "STAGE 1 CLEAR!" 배너와 짧은 번쩍임은 유지.
- 그 뒤 화면 전체가 검정으로 페이드(HUD 포함). 검은 화면에 흰 글씨로 감사 인사가 한 줄씩 나타나고 영상 끝까지 고정. 문구는 임시 초안이고, config.closing 배열로 뽑아서 내가 바꿀 수 있게 해 줘:
  - 오늘 이 자리에 함께해 주신 모든 분들께 진심으로 감사드립니다.
  - 서로 아끼고 존중하며 행복하게 살겠습니다.
  - 저희의 새로운 시작을 따뜻한 마음으로 축복해 주세요.
  - 신랑 {groom} · 신부 {bride}

## 정리/갱신
- 기존 config 구조(scenes, stage2, ending, finalCard 등)는 새 흐름에 맞게 자유롭게 재설계해도 돼. 단, config.js는 순수 데이터여야 하고, scripts/check-config.mjs도 새 구조에 맞게 고쳐서 아래를 검사하게 해: 총 길이 120초 미만(110초 초과 시 경고) / 멘트가 장면 구간을 벗어나지 않는지 / 멘트 겹침 / 장애물 점프·충돌 타이밍 겹침 / 하트가 0이 되지 않는지 / 배너 시간.
- BGM 큐(config.audioCues)를 새 흐름에 맞게 갱신: ① 잔잔한 곡은 1초부터 / ② 마리오풍은 GAME START 시점 / ③ 하이라이트는 신부를 만나는 시점. 정확한 초는 네가 계산한 값으로.
- docs/02_SCENARIO.md(장면표, 멘트, BGM 큐), docs/03_DECISIONS.md(이번 변경 결정), CLAUDE.md(스프라이트 방향/포즈 규칙)를 새 내용으로 갱신.
- 쓰지 않게 된 코드(스포트라이트, 피아노 방 배경 등)는 정리하되, 삭제 전에 무엇을 지웠는지 목록으로 보고해 줘.

## 진행 순서 (각 단계 끝에 캡처와 요약을 보여주고 내 확인을 받기)
A. 도트 24x32 개편 + 포즈/방향 시스템 + 걸음 이벤트 훅 (?t=로 각 포즈 확인할 수 있는 임시 확인 방법도 제안해 줘)
B. 오프닝(검정 배경, 오른쪽→왼쪽 걷기) + 인사 + 큰 말풍선
C. 맵 낙하 + HUD(하트, TIME) + 피아노 + 피아노 멘트
D. 달리기 + 글자 장애물 + 충돌/하트 + TIME 증가
E. 신부 만남 + 인사 + 페이드 + 마무리 감사 인사 + 문서/check 정리
