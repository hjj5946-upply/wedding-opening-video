> 시간/멘트의 **원본은 `src/config.js`** 입니다. 이 문서는 사람이 읽기 위한 요약이며, config를 바꾸면 같이 갱신하세요.
> `npm run check` 를 실행하면 최신 표가 터미널에 출력됩니다.

## 캐릭터
- 신랑: 검정 정장, 보타이, 가르마 머리
- 신부: 베일 드레스, 갈색 묶은 머리, 부케
- 현재는 **임시 코드 도트** (16×24칸). 정식 도트가 생기면 PNG 스프라이트로 교체
