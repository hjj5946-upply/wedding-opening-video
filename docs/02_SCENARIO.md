> mp3 효과음은 `public/assets/audio/` 에 두고 `config.sfx.<이름>.src` 에 파일 이름만 적으면 됩니다.
> 파일이 없으면 경고만 뜨고 **합성음으로 대신** 울립니다 (영상은 그대로 진행).
- **말풍선 말소리는 동물의 숲 느낌**: 부드러운 파형 + 살짝 디튠된 두 번째 음 + 음높이 글라이드 + 글자마다 다른 포먼트(입 모양). 글자마다 울리고 공백·문장부호는 건너뜁니다 (`config.sfx.blip*`)
- 주소 옵션: `?music=0` 음악만 끔 / `?sfx=0` 효과음만 끔 / `?mute=1` 전부 끔
