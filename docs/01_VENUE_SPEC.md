# 예식장(까사그랑데) 규격 및 일정

> 예식장 메일 2건을 정리한 것입니다. 원문과 다르면 원문이 우선입니다.

## 영상 규격
| 항목 | 내용 |
|---|---|
| 해상도 | 프레임 너비 1920 / 높이 1080 |
| 프레임레이트 | **60** (아니면 재생 시 깨질 수 있음 — 필수) |
| 형식 | MP4 (H.264 / AAC 권장) |
| 재생 | 팟플레이어 |
| 길이 | 식중 영상 2분 이내 |
| 개수 | 식중 영상은 **1개만** (오프닝/감사/축하 중 택일). 축가가 영상이면 추가 식중영상 제작 불가 |
| 용량 | 고용량이면 재생이 어려울 수 있음 → 작게 |
| 조명 | 축가 영상 진행 시 조명 사용 불가 (오프닝 영상도 해당되는지 **예식장에 확인 필요**) |
| 제작 기간 | 전문업체 의뢰 시 3주 이상 걸릴 수 있음 (직접 제작이라 해당 없음) |

## 기타 안내
- 성혼선언문은 낭독시간이 짧아 **BGM 재생 안 함**
- 제출한 자료는 **변경/수정 불가** → 제출 일자에 맞춰 **최종본**으로 회신
- 최초 제출 이후 추가/변경은 기존 압축파일/확인서에 **덮어쓰지 말고**, 이메일에 변경 내용만 적거나 변경된 파일만 별도로 발송
- 자료 테스트 후 문제 없으면 연락 없음, 이상 시 연락 / 문의: 대표전화 02-467-1002
- 회신 메일에 **예식일자와 신랑·신부 성함** 필수 기재

## 마감 일정
| 날짜 | 해야 할 일 |
|---|---|
| **11/12 (목)** | **최종확인서(엑셀) 마감** — 작성해서 회신. 이후 예식장이 유선으로 내용 확인 |
| **11/18 (수)** | **최종자료 마감** — 1차 식순(신랑입장/신부입장/행진 BGM 타이밍, 문열림·커튼열림 등 특별 타이밍 포함), 혼인서약서, 성혼선언문, 덕담(또는 축사 택1), **영상**, BGM, 축가MR, 차량번호, 버스번호, 식권이미지 등을 **알집 파일 하나로** 발송 |
| 본식 1주일 전까지 | 사회자 대본이 나중에 완성되면 2차로 회신 가능 |

혼인서약서/성혼선언문/덕담은 준비가 어려우면 당일 A4 한 장 분량 프린트물 지참 가능 (11/18까지 미제출 시 당일 지참으로 처리).
