## 2026-11-02 (P03-2 — 사진/거북이/엔딩 다듬기, 깜자 피드백 반영)
- **사진은 "우측 상단 액자"가 아니라 "상자에서 나오는 동그라미"로.** 물음표상자를 치는 행동과 사진이 떨어져 있으면 인과가 안 보임. 친 자리에서 동그랗게 떠올라 1.15초 뒤 "팡" 터지게 바꿈. 사각 액자 대신 원형이라 세로 사진도 얼굴 중심으로 보기 좋음(`photos.objectPosition`).
- **사진 동그라미 크기/높이는 "HUD와 안 겹치는 최대"로 역산.** 물음표상자가 화면 위쪽(y 280)에 있어서 그 위로 크게 띄우면 하트를 가림 → 지름 280px, 상자 중심에서 10px만 띄움. `npm run check` 가 HUD/자막칸과 겹치면 오류로 잡음.
- **원본 사진(최대 6.8MB, 합 25MB)은 그대로 쓰지 않고 1200px로 리사이즈해 배치.** 6000×4000 jpg 8장을 브라우저가 디코딩하면 수백 MB 메모리라 60fps가 위험. 리사이즈본만 깃에 올리고 원본은 `.gitignore` 로 제외(ffmpeg 없이 PowerShell System.Drawing 사용, EXIF 회전 반영).
- **글자 장애물의 글자를 뺐다.** 게임 구간 자막칸이 이미 이야기를 하고 있어서 장애물 글자까지 있으면 읽을 게 두 군데가 됨. 크기도 줄여 "달리다 만나는 벽돌"로.
- **거북이는 밟는 적이 아니라 "넘어가는 장애물".** 밟기/죽기 연출은 결혼식 영상에 어울리지 않고, 하트는 이미 벽돌 2개로 2번 깎임. 맵보다 60px/초 빠르게 기어오게 해서 "다가온다"는 느낌만 줌.
- **장식 벽돌을 물음표상자보다 위(y 196)로 올림.** 원래 y 440에 있어서 점프한 신랑과 겹쳐 "부딪힌 것처럼" 보였음.
- **STAGE 1 CLEAR 삭제.** 대신 STAGE 1 START(게임 시작, 1 YEAR 직전에 사라짐) / STAGE 2 START(둘이 손잡고 걸어갈 때)로 바꿔 "1막이 끝나고 2막이 시작된다"는 이야기를 배너로 전달.
- **outro 는 신부를 만나는 순간(69.6초)부터.** 페이드가 시작될 때 틀면 늦음 — 만나는 순간 음악이 바뀌어야 감정이 올라감.
- **깃발 뒤 걸어가는 2.4초에만 walk.mp3 를 낮은 볼륨으로.** 음악이 없는 구간이라 발소리라도 있어야 허전하지 않음.
- **말풍선 소리를 "비프음"에서 "말소리"로.** 단순 사각파 비프는 기계음이라 동물의 숲 느낌이 안 남. ① 부드러운 파형 + 살짝 디튠된 두 번째 음(목소리 두께) ② 소리 중 음높이 하강(억양) ③ 글자마다 다른 밴드패스 포먼트(입 모양이 바뀌는 느낌) 로 바꿈.
- **신부 걷기 프레임을 새로 그림.** 둘이 손잡고 걸어가려면 신부도 걸어야 하는데 옆모습 서기만 있었음. 긴 드레스라 다리 대신 밑단 3가지와 팔 높이로 4프레임 구성.

## 2026-11-02 (P03 — 게임 구간 개편 · 음악 직접 재생)
- **방침 변경: 음악을 웹페이지가 직접 재생한다.** 기존 "BGM은 편집 단계에서 입힘" 규칙을 폐기. OBS 데스크톱 오디오로 화면과 소리를 한 번에 녹음하고, 편집 툴에서는 앞뒤 자르기/페이드/내보내기만 함. 이유: 영상 편집 경험이 없는 깜자에게 음악 싱크 맞추기가 가장 어려운 작업이었고, 타임라인에서 큐를 잡으면 `?t=` 로 몇 번이든 똑같이 확인할 수 있음.
- **Web Audio(디코딩 버퍼 예약 재생)를 씀.** HTMLAudio 는 `currentTime` 설정이 느리고 시킹에 지연이 있어 영상 시각과 어긋남. mp3 3개를 스페이스바 전에 미리 디코딩하고, 매 프레임 "영상 시각 ↔ 음악 위치"를 비교해 0.25초 이상 벌어지면 다시 맞춤 → `?t=`, ←/→, 숫자키, P(일시정지)에서도 음악이 따라옴.
- **"PRESS SPACE" 안내는 mp3 디코딩이 끝난 뒤에만 표시.** 글자가 보이면 소리가 제때 난다는 신호 — 녹화 시작 타이밍을 알려 주는 역할도 함.
- **게임 구간을 30초로 압축** (기존 40초). 전체 108초 → **101초**. 달리기만 하던 구간이 지루하다는 피드백 때문에, 2초 간격으로 사건(상자/낭떠러지/장애물)이 끊기지 않게 배치.
- **물음표상자 8개 = 1년~8년.** TIME 은 스크롤 거리 비례가 아니라 **상자를 칠 때마다** 올라가게 바꿈(0 → 1 → … → 8). 숫자가 올라가는 이유가 화면에 보여야 이야기가 전달되기 때문. 깃발을 치면 "8 YEAR 6 MONTH" 로 마무리.
- **사진은 없어도 돌아가게.** `year1.jpg ~ year8.jpg` 가 없으면 "N YEAR" 글자 액자를 대신 띄움(`<img onError>`). 재료가 늦게 준비돼도 전체 흐름을 계속 확인할 수 있어야 함.
- **게임 구간 말풍선은 캐릭터에서 떼어 화면 아래 고정 자막칸**(`layout: 'game'`)으로. 달리는 캐릭터 머리 위에 두면 물음표상자·사진 팝업과 계속 겹침. 최대 2줄로 제한하고 타이핑 속도는 16자/초.
- **사진 팝업은 오른쪽 위**(HUD TIME 아래). 왼쪽 위는 하트, 아래는 자막칸이라 남는 자리가 여기뿐.
- **낭떠러지는 "떨어질 수 있는 구멍"이 아니라 연출**이다. 점프 시각을 config 로 지정하므로 항상 성공하고 하트도 안 닳음. 실패 연출을 넣으면 하객이 불안해짐.
- **맵은 계단 꼭대기에서 멈춘다.** 멈추는 시각을 계단 칸 수 × 칸 폭 ÷ 속도로 **자동 계산**(`mapStopAt`)해서, 계단·깃발·신부 위치가 전부 여기에 맞춰 따라오게 함.
- **글자 장애물은 3개로 줄임**(기존 4개), 그중 2개만 충돌. 시간 예산 때문.
- **비프음을 글자마다**로 변경(`blipEveryNChars: 1`, 문장당 제한 해제). 대신 공백·문장부호는 건너뛰고, 최소 간격 0.035초 · 동시 소리 6개 제한 · 피치 ±6% 랜덤으로 지직거림과 단조로움을 막음.
- **효과음은 전부 오실레이터 합성.** 저작권 있는 샘플을 쓰지 않기 위해서 (상자 '통', 하트 '뿅', 회복, 깃발).
- **마지막은 완전한 검정으로 끝낸다.** 감사 인사가 한 줄씩 떠올랐다 사라지고 검정으로 마무리 — 예식장 "마지막 화면 고정" 규격은 검은 화면으로 충족.
- **피아노는 실제 이미지(grandPiano.png)로 교체.** 건반이 왼쪽을 향한 그림이라, 신랑이 건반 앞에 서 보이도록 피아노 x를 역산해서 배치(`piano.x`). 말풍선이 피아노 윗부분을 조금 가리지만 신랑과 건반은 가려지지 않음.
- **피아노 장면 멘트는 초안 2줄로 원복**하고, "작업만 쳤습니다" 등은 게임 구간 멘트로 옮김 (깜자 요청).

## 2026-11-02 (P02 E단계 — 신부 만남 · 마무리)
- **페이드/마무리 구간을 앞당김**: fade 90~96 / closing 96~108 → **fade 90~94 / closing 94~108**. 6초 페이드는 너무 늘어지고, 감사 인사 4줄을 읽을 시간이 더 필요해서. (2초 동안 검정으로 덮고 → 2초 정적 → 94.6초부터 한 줄씩)
- **마무리 감사 인사는 말풍선이 아니라 화면 글자(`config.closing`)**. 한 번 나타난 줄은 사라지지 않고 끝까지 고정 — "마지막 화면 고정" 규격을 자연스럽게 만족.
- **`config.finalCard` 삭제 → `config.closing` 으로 통합.** 마지막 카드(두 번째 스테이지/이름/날짜)는 감사 인사 마지막 줄("신랑 · 신부")이 역할을 대신함. 날짜는 청첩장·식순에 이미 있어 화면에서 뺌(필요하면 `closing.lines` 에 한 줄 추가).
- **검정 페이드는 전용 층(`.blackout`, z-index 10)으로 HUD·배너 위까지 전부 덮음.** 요소별로 하나씩 끄면 타이밍이 어긋나고 되감기에 취약해서.
- **신부는 "등장"시키지 않고 맵 끝에 계속 서 있게 둠.** 달리는 동안 78초쯤 화면 오른쪽에 자연스럽게 들어오고, 그때부터 신랑 쪽(왼쪽)을 바라보는 옆모습. 갑자기 나타나는 것보다 "달려가서 만난다"는 느낌이 살아남.
- **하트는 가운데에서 좌우로 번갈아 퍼지는 분수 모양**(처음엔 한 덩어리로 뭉쳐 보였음). 또 STAGE 1 CLEAR 배너 글자를 가리지 않도록 낮게(바닥선 위 280px) 띄우고 배너(86.0초) 전에 끝나게 맞춤.
- **멘트 길이 경고 기준을 "36자 고정"에서 "말풍선 배치별 3줄 기준"으로 변경**(`maxCharsForLine`). side는 약 57자, above는 약 60자. 함께 `bubble.above.maxWidth` 를 1100 → **1400** 으로 늘려 긴 멘트가 4줄로 넘치지 않게 함.
- **BGM③ 큐는 80.0초(맵 정지)**, 두 사람이 만나는 83.2초는 "하이라이트 절정" 메모로 따로 남김. 곡이 미리 깔려 있어야 만나는 순간에 절정이 맞음.

## 2026-11-02 (P02 D단계 — 달리기 구간)
- **글자 장애물은 "시각"으로만 적는다**: 점프는 `apexAt`, 충돌은 `hitAt`. 맵 위 x좌표는 `engine/timing.js` 가 계산하고 화면·타임라인·`npm run check` 가 모두 같은 함수를 씀. → BGM 비트에 맞출 때 숫자 하나만 고치면 됨.
- **충돌한 장애물은 "앞으로 넘어지며 사라짐"** (부서지는 파편 대신). 맵은 계속 흐르는데 신랑이 통과해야 해서 장애물이 없어져야 하고, 파편을 많이 만들면 60fps가 위험하기 때문. 회전 1개 + 투명도 1개짜리 가벼운 연출.
- **하트는 1개를 반드시 남김**: 부딪히는 장애물 2개(우여곡절·일들이) → 3 → 2 → 1. `npm run check` 가 0이 되면 오류로 잡음.
- **TIME은 `hud.time.fullAt`(68초)에서 8 YEAR 도달**: 달리기 끝(80초)이 아니라 마지막 장애물 직후에 8이 되게 맞춤 — 바로 뒤 멘트 "8년 6개월"과 화면 숫자가 어긋나지 않게.
- **GAME START 배너에 "STAGE 1" 부제를 함께 표시** (P02 제안 채택). 40.0초 = BGM② 전환 지점.
- **깜빡임은 `.bob`(도트)에만 적용** — 말풍선이 같이 깜빡이지 않게.

## 2026-11-02
- **컨셉 확정: 순수 게임풍(A안).** 우주 줌인(B안) 도입부는 삭제. (사용자 결정)
- **스토리 구조**: STAGE 1(인사 + 피아노 학원 연애 스토리, 유머) → STAGE 2(달리며 점프) → 신부 만남. 멘트는 초안으로 진행하고 나중에 수정.
- **BGM 3구간**: ① 페이커 롤드컵 곡(잔잔) → ② 슈퍼마리오풍(점프 구간, 크게) → ③ 페이커 곡 하이라이트(마무리). 웹은 화면만, 음악은 편집에서 입힘.
- **캐릭터**: 신랑 검정 정장+보타이+가르마 / 신부 베일 드레스+갈색 묶은머리. 정식 도트 전까지 **임시 코드 도트** 사용.
- **프레임레이트 60fps로 정정**: 처음에 30fps로 안내했으나 예식장 최종 안내 메일에서 60fps 필수로 확인됨. 녹화(OBS)와 내보내기 모두 60fps.
- **화면 하단 글자 제한 항목 삭제**: 빔프로젝터 상영이라 가려지지 않는다는 사용자 확인. 지침에서 제외.
- **협업 방식**: 깜자(총괄) + 채팅 Claude(기획/프롬프트/문서) + Claude Code(구현), 저장소는 GitHub.
- **임시 도트 방식**: 사각형 목록(`sprites/*.js`)으로 그림. 나중에 PNG로 바꿀 때 `PixelSprite`만 이미지 방식으로 교체.
- **효과음**: 말소리 "뿅뿅"만 웹(Web Audio)에서 생성. 기본값은 문장 시작 때 최대 3번(`sfx.blipMaxPerLine`). 계속 "뿅뿅뿅" 하려면 값을 크게.
- **점프 타이밍 방식**: 장애물 위치를 직접 정하지 않고 "신랑이 장애물 위에 오는 시각(`apexAt`)"을 정하면 위치가 자동 계산됨 (음악 비트에 맞추기 쉬움).
- **시간 이동 안전 설계**: 포즈·글자 타이핑은 현재 시각으로 계산 → `?t=초` 와 디버그 이동이 정확히 동작.
