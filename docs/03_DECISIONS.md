## 2026-11-03 (P04-4 — 쇼팽반 팻말 / 점프·코인 효과음 mp3)
- **효과음도 mp3를 쓸 수 있게 함.** `config.sfx.<이름>.src` 에 파일 이름을 적으면 그 mp3를, 없으면 지금까지처럼 오실레이터 합성음을 씁니다. 짧은 소리라 음악 큐와 달리 **미리 디코딩해 두고 필요할 때마다 즉시 재생**(`loadSfxSamples` / `playSample`). 파일을 못 찾아도 합성음으로 대체돼 영상은 그대로 돌아갑니다.

- **벽돌 충돌음을 'box' 에서 'hit' 으로 분리.** 전에는 상자 소리를 같이 썼는데, 상자가 코인 소리로 바뀌면서 "부딪혔는데 동전 소리"가 나기 때문. 충돌은 둔탁한 합성 '퉁'.
- **피아노 학원 벽에 "쇼팽반" 팻말 추가** (`config.room.sign`). 문구/위치/크기는 config 에서 바꿉니다.

## 2026-11-02 (P03 — 게임 구간 개편 · 음악 직접 재생)
- **방침 변경: 음악을 웹페이지가 직접 재생한다.** 기존 "BGM은 편집 단계에서 입힘" 규칙을 폐기. OBS 데스크톱 오디오로 화면과 소리를 한 번에 녹음하고, 편집 툴에서는 앞뒤 자르기/페이드/내보내기만 함. 이유: 영상 편집 경험이 없는 깜자에게 음악 싱크 맞추기가 가장 어려운 작업이었고, 타임라인에서 큐를 잡으면 `?t=` 로 몇 번이든 똑같이 확인할 수 있음.
- **Web Audio(디코딩 버퍼 예약 재생)를 씀.** HTMLAudio 는 `currentTime` 설정이 느리고 시킹에 지연이 있어 영상 시각과 어긋남. mp3 3개를 스페이스바 전에 미리 디코딩하고, 매 프레임 "영상 시각 ↔ 음악 위치"를 비교해 0.25초 이상 벌어지면 다시 맞춤 → `?t=`, ←/→, 숫자키, P(일시정지)에서도 음악이 따라옴.
- **"PRESS SPACE" 안내는 mp3 디코딩이 끝난 뒤에만 표시.** 글자가 보이면 소리가 제때 난다는 신호 — 녹화 시작 타이밍을 알려 주는 역할도 함.
- **게임 구간을 30초로 압축** (기존 40초). 전체 108초 → **101초**. 달리기만 하던 구간이 지루하다는 피드백 때문에, 2초 간격으로 사건(상자/낭떠러지/장애물)이 끊기지 않게 배치.
- **물음표상자 8개 = 1년~8년.** TIME 은 스크롤 거리 비례가 아니라 **상자를 칠 때마다** 올라가게 바꿈(0 → 1 → … → 8). 숫자가 올라가는 이유가 화면에 보여야 이야기가 전달되기 때문. 깃발을 치면 "8 YEAR 6 MONTH" 로 마무리.
- **사진은 없어도 돌아가게.** `year1.jpg ~ year8.jpg` 가 없으면 "N YEAR" 글자 액자를 대신 띄움(`<img onError>`). 재료가 늦게 준비돼도 전체 흐름을 계속 확인할 수 있어야 함.
- **게임 구간 말풍선은 캐릭터에서 떼어 화면 아래 고정 자막칸**(`layout: 'game'`)으로. 달리는 캐릭터 머리 위에 두면 물음표상자·사진 팝업과 계속 겹침. 최대 2줄로 제한하고 타이핑 속도는 16자/초.
- **사진 팝업은 오른쪽 위**(HUD TIME 아래). 왼쪽 위는 하트, 아래는 자막칸이라 남는 자리가 여기뿐.
- **낭떠러지는 "떨어질 수 있는 구멍"이 아니라 연출**이다. 점프 시각을 config 로 지정하므로 항상 성공하고 하트도 안 닳음. 실패 연출을 넣으면 하객이 불안해짐.
- **맵은 계단 꼭대기에서 멈춘다.** 멈추는 시각을 계단 칸 수 × 칸 폭 ÷ 속도로 **자동 계산**(`mapStopAt`)해서, 계단·깃발·신부 위치가 전부 여기에 맞춰 따라오게 함.
- **글자 장애물은 3개로 줄임**(기존 4개), 그중 2개만 충돌. 시간 예산 때문.

- **효과음은 전부 오실레이터 합성.** 저작권 있는 샘플을 쓰지 않기 위해서 (상자 '통', 하트 '뿅', 회복, 깃발).

## 2026-11-02 (P02 D단계 — 달리기 구간)
- **글자 장애물은 "시각"으로만 적는다**: 점프는 `apexAt`, 충돌은 `hitAt`. 맵 위 x좌표는 `engine/timing.js` 가 계산하고 화면·타임라인·`npm run check` 가 모두 같은 함수를 씀. → BGM 비트에 맞출 때 숫자 하나만 고치면 됨.
