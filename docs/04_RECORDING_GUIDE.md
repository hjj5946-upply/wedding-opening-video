# 녹화 → 편집 → 제출 가이드 (Windows)

> 용어 풀이: **fps**(프레임레이트)는 1초에 그림이 몇 장 바뀌는지. 60fps는 1초에 60장이라 더 부드럽습니다. **인코딩**은 영상을 MP4 같은 파일로 압축해 저장하는 과정이에요.

## 0. 녹화 전 준비
1. 모니터 해상도 **1920×1080**, 윈도우 디스플레이 배율 **100%** (설정 → 시스템 → 디스플레이)
2. 크롬에서 `npm run dev` 화면을 열고 `?debug=1` 로 한 번 끝까지 재생해 보며 타이밍 확인
3. 다른 프로그램/탭을 모두 닫고, 알림 소리 끄기 (말소리 효과음에 섞일 수 있음)
4. 디버그 표시는 **꺼두기** (D 키). 마우스 커서는 자동으로 숨겨짐

## 1. OBS Studio 설정 (처음 한 번)
- 설정 → 비디오: 기본(캔버스) 해상도 **1920×1080**, 출력(조정) 해상도 **1920×1080**, FPS **60**
- 설정 → 출력 → 녹화: 형식 **mkv**(도중에 꺼져도 파일이 안 깨짐), 인코더 x264 또는 NVENC(H.264), 품질은 "고품질/CRF 18~20"
- 소스: **디스플레이 캡처**(모니터 전체)를 추가. 소리: **데스크톱 오디오**는 켬(말소리 효과음 녹음용), 마이크는 끔
- 녹화가 끝나면 파일 → 리먹싱 으로 mkv를 mp4로 변환

## 2. 녹화
1. 크롬 **F11 전체화면** → OBS에서 녹화 시작
2. 2~3초 기다렸다가 **스페이스바** (영상 시작)
3. 마지막 화면(이름/날짜 카드)에서 3~5초 더 기다린 뒤 녹화 중지
4. 한 번에 실패하면 **R** 로 처음으로 돌아가 다시 (여러 번 찍어서 가장 부드러운 것 선택)

## 3. 편집 툴에서 (클립챔프 또는 캡컷) — 해야 할 일은 4가지뿐
1. **앞뒤 자르기**: 스페이스바 누르기 전 대기 구간과 끝 대기 구간을 잘라냄. 영상은 검은 화면으로 시작해야 함
2. **BGM 입히기** (`02_SCENARIO.md` 의 음악 큐 참고)
   - ① 페이커 곡: 영상 1초부터, 볼륨 낮게 (말소리 효과음이 들리게)
   - ② 마리오풍: 62초에서 전환, 크게
   - ③ 페이커 하이라이트: 92초에서 전환. 곡 전환 부분은 페이드 인/아웃을 1~2초 줘서 자연스럽게
   - 영상 끝에서 음악도 자연스럽게 페이드 아웃
3. **길이 확인**: 2분(120초) 미만
4. **내보내기**: **1080p(1920×1080) / 60fps / MP4**. 캡컷은 엔딩 로고·워터마크가 자동으로 붙지 않는지 확인

## 4. 최종 점검 (제출 전)
- [ ] 파일 우클릭 → 속성 → 자세히: 프레임 너비 1920 / 높이 1080 / **프레임 속도 60**
- [ ] 길이 2분 미만
- [ ] **팟플레이어**에서 직접 재생: 소리, 끊김, 시작이 검은 화면인지, 마지막 화면 고정인지
- [ ] 용량 확인 — 1080p 60fps 108초는 보통 수십~150MB 정도. 너무 크면 HandBrake(무료)로 H.264 재인코딩(비트레이트 8~10Mbps 정도)
- [ ] 알집 하나에 다른 자료(식순, BGM, 축가MR 등)와 함께 담아 메일 발송 (`01_VENUE_SPEC.md` 참고)

## 문제 해결
| 증상 | 원인/해결 |
|---|---|
| 녹화본에서 맵 이동이 끊김 | 다른 프로그램 종료, 크롬 하드웨어 가속 켜기, OBS 인코더를 NVENC로, `?t=` 없이 새로 열기 |
| 화면 크기가 틀어짐 | 디스플레이 배율 100% 확인, 크롬 F11 전체화면 |
| 말소리 효과음이 안 녹음됨 | OBS 데스크톱 오디오 켬 확인, 크롬 소리 허용(스페이스바 눌러야 소리 허용됨) |
| 파일 속성이 60fps가 아님 | 편집 툴 내보내기에서 프레임 60 지정 |
