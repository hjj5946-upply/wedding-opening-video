# 녹화 → 편집 → 제출 가이드 (Windows)

> 용어 풀이: **fps**(프레임레이트)는 1초에 그림이 몇 장 바뀌는지. 60fps는 1초에 60장이라 더 부드럽습니다. **인코딩**은 영상을 MP4 같은 파일로 압축해 저장하는 과정이에요.
>
> **중요 — 바뀐 점:** 이제 **음악(BGM)과 효과음이 웹페이지 안에서 직접 재생**됩니다.
> OBS의 **데스크톱 오디오**로 화면과 소리를 한 번에 녹음하면 되고, 편집 툴에서는 **앞뒤 자르기 / 페이드 / 내보내기**만 하면 됩니다. (음악을 따로 입힐 필요 없음)

## 0. 녹화 전 준비
1. 모니터 해상도 **1920×1080**, 윈도우 디스플레이 배율 **100%** (설정 → 시스템 → 디스플레이)
2. `public/assets/audio/` 에 **intro.mp3 / inGame.mp3 / outro.mp3 / walk.mp3** 4개가 있는지 확인
   (깃에 안 올라가므로 **다른 PC에서는 USB 등으로 따로 복사**해야 합니다)
3. `public/assets/photos/` 에 **year1.jpg ~ year8.jpg** 가 있는지 확인 (이미 넣어 뒀습니다. 바꾸고 싶으면 같은 이름으로 덮어쓰고 긴 변 1200px 이하 jpg 권장)
4. 크롬에서 `npm run dev` 화면을 열고 한 번 끝까지 재생해 보며 타이밍/소리 확인
5. 다른 프로그램/탭을 모두 닫고, **윈도우 알림 소리 끄기** (데스크톱 오디오로 같이 녹음됩니다!)
6. 디버그 표시는 **꺼두기** (D 키). 마우스 커서는 자동으로 숨겨짐
7. **윈도우 볼륨을 적당히** (너무 크면 찌그러지고, 너무 작으면 나중에 못 키웁니다). 윈도우 볼륨 믹서에서 크롬만 남기면 안전

## 1. OBS Studio 설정 (처음 한 번)
- 설정 → 비디오: 기본(캔버스) 해상도 **1920×1080**, 출력(조정) 해상도 **1920×1080**, FPS **60**
- 설정 → 출력 → 녹화: 형식 **mkv**(도중에 꺼져도 파일이 안 깨짐), 인코더 x264 또는 NVENC(H.264), 품질 "고품질/CRF 18~20"
- 소스: **디스플레이 캡처**(모니터 전체) 추가
- 소리: **데스크톱 오디오 켬** (음악 + 효과음이 전부 여기로 녹음됩니다), **마이크는 끔**
- 오디오 믹서에서 데스크톱 오디오 레벨이 **노란 구간(-12 ~ -6dB)** 정도로 흔들리게 윈도우 볼륨 조절. 빨간색(0dB)까지 치면 소리가 찌그러집니다
- 녹화가 끝나면 파일 → 리먹싱 으로 mkv를 mp4로 변환

## 2. 녹화
1. 크롬 **F11 전체화면** → 화면 아래 **"PRESS SPACE"** 글자가 뜰 때까지 기다립니다
   (음악 파일을 미리 읽는 중입니다. 이 글자가 떠야 소리가 제때 나옵니다)
2. OBS에서 녹화 시작
3. 2~3초 기다렸다가 **스페이스바** (영상 시작 — 이때 소리 허용이 풀립니다)
4. 마지막에 화면이 완전히 검어진 뒤 **3~5초 더** 기다렸다가 녹화 중지
5. 한 번에 실패하면 **R** 로 처음으로 돌아가 다시 (여러 번 찍어서 가장 부드러운 것 선택)

> 소리 없이 화면만 녹화하고 싶으면 주소 끝에 `?mute=1` 을 붙이세요.
> 음악만 끄려면 `?music=0`, 비프음/효과음만 끄려면 `?sfx=0` 입니다.

## 3. 편집 툴에서 (클립챔프 또는 캡컷) — 이제 할 일은 3가지뿐
1. **앞뒤 자르기**: 스페이스바 누르기 전 대기 구간과 끝 대기 구간을 잘라냄. 영상은 **검은 화면으로 시작**해야 함
2. **페이드**(선택): 맨 앞 0.3초 페이드 인, 맨 뒤 0.5초 페이드 아웃 정도만. 영상 자체가 검정으로 끝나므로 없어도 괜찮습니다
3. **내보내기**: **1080p(1920×1080) / 60fps / MP4**. 캡컷은 엔딩 로고·워터마크가 자동으로 붙지 않는지 확인

> 음악 볼륨이 마음에 안 들면 편집 툴에서 만지지 말고 **`src/config.js` 의 `audio.tracks.<곡>.volume`** 을 고친 뒤 다시 녹화하는 게 깔끔합니다.

## 4. 최종 점검 (제출 전)
- [ ] 파일 우클릭 → 속성 → 자세히: 프레임 너비 1920 / 높이 1080 / **프레임 속도 60**
- [ ] 길이 2분 미만 (지금 영상은 약 115.5초)
- [ ] **팟플레이어**에서 직접 재생: 소리(음악 + 비프음), 끊김, 시작이 검은 화면인지, 끝이 검은 화면인지
- [ ] 소리가 너무 크거나 작지 않은지 (예식장 스피커는 보통 더 크게 들립니다)
- [ ] 용량 확인 — 1080p 60fps 115.5초는 보통 수십~150MB 정도. 너무 크면 HandBrake(무료)로 H.264 재인코딩(비트레이트 8~10Mbps 정도)
- [ ] 알집 하나에 다른 자료(식순, 축가MR 등)와 함께 담아 메일 발송 (`01_VENUE_SPEC.md` 참고)

## 문제 해결
| 증상 | 원인/해결 |
|---|---|
| "PRESS SPACE" 가 안 뜸 | mp3 파일이 `public/assets/audio/` 에 없거나 이름이 다름 (intro.mp3 / inGame.mp3 / outro.mp3 / walk.mp3) |
| 소리가 하나도 안 남 | 스페이스바를 눌러야 소리가 허용됩니다. 주소에 `?mute=1` `?music=0` 이 붙어 있지 않은지 확인 |
| 음악이 녹화본에 안 들어감 | OBS **데스크톱 오디오**가 켜져 있는지 확인 (마이크 아님) |
| 음악이 말소리 비프음을 덮음 | `config.audio.tracks.<곡>.volume` 을 낮추거나 `config.sfx.volume` 을 올리세요 |
| 녹화본에서 맵 이동이 끊김 | 다른 프로그램 종료, 크롬 하드웨어 가속 켜기, OBS 인코더를 NVENC로, `?t=` 없이 새로 열기 |
| 화면 크기가 틀어짐 | 디스플레이 배율 100% 확인, 크롬 F11 전체화면 |
| 사진이 안 보이고 "N YEAR" 글자만 나옴 | `public/assets/photos/year1.jpg ~ year8.jpg` 가 있는지 확인 (파일 이름이 정확해야 합니다) |
| 파일 속성이 60fps가 아님 | 편집 툴 내보내기에서 프레임 60 지정 |
