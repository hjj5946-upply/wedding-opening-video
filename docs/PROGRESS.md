## 임시로 처리한 것 / 확인하지 못한 것
- **사진**: 넣어 주신 8장을 1200px로 줄여 배치 완료. 세로 사진이 많아 동그라미에 얼굴이 잘릴 수 있으니 `config.photos.objectPosition`(기본 `center 38%`)으로 조절하세요
- **잡은 손**: 전용 도트가 없어 두 사람 사이를 잇는 **작은 살색 막대**로 대신했습니다 (임시)
- **거북이**: 다리만 2프레임으로 움직이는 오리지널 도트. 지나가는 1.5초 동안만 보입니다
- **꾸벅 인사 모션**: 도트에 "인사" 프레임이 없어서, 손 흔들기 + `.bob` 을 아래로 숙이는 **코드 모션**으로 대신함. 전용 프레임(`bow_1` 등)을 그리면 더 자연스러워짐
- **mp3 평균 음량 측정 실패**: ffmpeg/ffprobe 가 없어 길이만 확인(intro 40.54초 / inGame 125.15초 / outro 42.48초 / walk 22.58초). **볼륨은 보수적인 기본값이니 귀로 듣고 조정 필요**
- **실제 소리 재생은 미확인**: 헤드리스 환경에서는 들을 수 없어 "디코딩 성공 + 콘솔 에러 없음"까지만 확인함
- **60fps 실측 미확인**: 실제 PC에서 전체 재생해야 알 수 있음
